## 一、环境要求与 5 分钟跑起来

### 1.1 环境要求

| 项目 | 要求 |
|---|---|
| PHP | 7.3 及以上（推荐 8.x），需启用 `pdo_mysql`、`session`、`gd`（缩略图，可选） |
| 数据库 | MySQL 5.5.3 及以上（`utf8mb4` 起始版本），推荐 5.7 / 8.0 |
| Web 服务器 | Apache / Nginx / IIS 均可，站点根目录指向 `src/`；伪静态配置见 7.11 节 |
| 构建工具 | 无。不需要 Node、Composer、Vite |
| 可写目录 | `src/store/`（配置、缓存、上传） |

PHP 7.3 为最低可用版本；会话 Cookie 的 `SameSite` 属性在 7.3 及以上原生支持。

### 1.2 五步启动

1. 把 `src/` 部署到 Web 根目录（或把虚拟主机根目录指向 `src/`）。
2. 确认 `src/store/` 可写。
3. 在 MySQL 中新建空库，例如 `fcontex_admin`。
4. 浏览器访问站点首页（缺数据库配置时会自动跳转安装向导），或直接访问 `http://你的域名/install/index.php`，填写数据库连接与管理员账号。
5. 安装完成后访问 `http://你的域名/` 进入后台登录页。

安装向导会：建表、写入初始数据、生成 `src/store/config/system.database.php` 等配置文件。重复安装前请自行备份。

### 1.3 本地快速验证

```bash
# 语法检查
find src -name "*.php" -exec php -l {} \;
```

## 二、目录结构与请求生命周期

### 2.1 目录结构

```
src/
├── index.php                 入口，加载 startup 后交给路由
├── install/                  安装向导（含 mysql.sql）
├── store/                    运行时存储（可写）
│   ├── config/               自动生成的配置 system.database.php / system.modules.php ...
│   ├── cache/                页面缓存、缩略图
│   └── upload/               上传文件
└── module/
    ├── startup.php           引导层：常量、session、全局对象
    ├── system/               内核（不可禁用）
    │   ├── module.php        模块声明（信息/权限/菜单/回调）
    │   ├── index.php         页面入口
    │   ├── control/index.php 动作接口
    │   ├── library/          内核类库
    │   ├── template/         后台模板
    │   └── icons/            图标
    ├── member/               内核（用户与用户组）
    ├── content/              业务模块（内容、栏目、标签、前台主题）
    └── message/              业务模块（评论、留言）
```

每个模块的固定组成：

| 路径 | 作用 | 是否必需 |
|---|---|---|
| `module.php` | 模块元信息、权限、菜单、安装/卸载回调 | 是 |
| `index.php` | 页面渲染入口（GET） | 是 |
| `control/index.php` | 动作接口（POST，`?mode=fc.实体.动词`） | 按需 |
| `library/cls.<name>.php` | 模块类库 | 按需 |
| `template/*.php` | 后台页面模板 | 按需 |
| `icons/` | 模块与权限图标 | 按需 |
| `install.mysql.sql` | 模块数据表 | 按需 |

### 2.2 请求生命周期

```
index.php
 └─ module/startup.php
     ├─ 定义常量（PATH_* / URL_*）
     ├─ 创建全局对象 $A $U $D $T $R
     └─ $R->dispatch()
         ├─ 解析 QUERY_STRING → module / action / params
         ├─ include module/<module>/index.php
         └─ 输出缓冲 → 可选页面缓存 → echo
```

全局对象：

| 变量 | 类 | 用途 |
|---|---|---|
| `$A` | `FCApplication` | 配置、工具函数、日志、Cookie、上传 |
| `$U` | `member` | 登录态、权限校验、皮肤 |
| `$D` | `FCDataBaseDriver` | 数据库出口（见第四节） |
| `$T` | `template` | 模板绑定与渲染 |
| `$R` | `router` | 路由、URL 生成、404 |

查询构造器不在全局对象中，按需获取（`DB` 门面定义在 `cls.database.php`，由 `startup.php` 预加载；每次调用返回新实例）：

```php
$Q = DB::table('device');
```

### 2.3 页面与动作分离

- **页面入口** `module/<m>/index.php`：只读、渲染 HTML。
- **动作接口** `module/<m>/control/index.php`：读写数据，返回 `YES` 或 `ERR|消息|字段名`。

动作接口的第一件事必须是权限校验：

```php
if (!$U->checkRights('content.insert')) exit('ERR|'.ERROR_NO_RIGHTS);
```

### 2.4 后台 URL 与深链接

后台桌面入口是 `?system`。在 `#` 后追加 `模块名/窗口action`，即可在打开桌面时直接弹出对应窗口：

```
/?system#member/fc.user.select     打开「用户管理」窗口
/?system#content/fc.content.select 打开「内容管理」窗口
```

- `#` 后面的部分是**深链接参数**，格式固定为 `模块名/窗口action`，与菜单项的 `navigate` 属性一致（见 `menus.php`）
- 页面加载时 `start.php` 的 `naviOpen()` 读取 `location.hash`，选中对应模块竖栏并触发该菜单项，等价于手动点击
- 后续切换菜单会同步更新 `location.hash`（`$$.target()`），因此刷新或复制地址都能还原到当前窗口
- 该参数只作用于**桌面窗口的打开**，不参与服务端路由与鉴权；权限仍由窗口内页面的 `checkRights` 决定
- **页面跳转与控制器地址不能混用**：页面走页面路由，如 `$R->getPageUrl('system/fc.files.server')` → `/?system/fc.files.server&show=image`；`?mode=fc.xxx` 只属于控制器地址（`/module/<模块>/control/?mode=fc.xxx`）。把 `?mode=fc.xxx` 当页面地址用，会被解析成不存在的模块名，最终 404（`fc.files.server` 的筛选/搜索链接曾踩过此坑）

```
src/module/device/
├── module.php
├── index.php
```

### 第二步：声明 `module.php`

类名必须是 `FCModule` + 目录名首字母大写，否则内核识别不到。

```php
<?php
final class FCModuleDevice
{
	public $basic = array
	(
		'for'     => '1.0.1+',
		'name'    => '设备管理',
		'icon'    => 'module.png',
		'desc'    => '设备台账与状态管理。',
		'author'  => 'yourname',
		'contact' => 'you@example.com',
		'version' => '1.0',
		'update'  => '2026.11',
		'support' => 'www.fcontex.com',
	);
	
	//权限键全局唯一，统一用 模块名.实体.动词 形式
	public $rights = array
	(
		'device.select' => '设备查看',
		'device.insert' => '设备添加',
		'device.update' => '设备编辑',
		'device.delete' => '设备删除',
	);
	
	public $menus = array
	(
		//单组模块：组名与模块名一致 不配组图标（回落模块图标）
		'设备管理' => array
		(
			'items' => array
			(
				'设备管理' => array('url'=>'fc.device.select', 'icon'=>'module.png', 'rights'=>'device.select'),
			)
		),
	);
	
	public function install() {}
	public function uninstall() {}
}
?>
```

复杂模块可以声明多个分组（组不设权限，组内叶子各自引用权限），例如 ERP 模块：

### 第三步：数据表 `install.mysql.sql`

表名统一用 `fc_` 前缀，安装时自动替换为配置中的前缀。

```sql
CREATE TABLE IF NOT EXISTS `fc_device` (
  `dv_id` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `dv_name` varchar(100) NOT NULL DEFAULT '',
  `dv_status` tinyint(1) NOT NULL DEFAULT '1',
  `dv_inserttime` int(10) unsigned NOT NULL DEFAULT '0',
  PRIMARY KEY (`dv_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci;
```

### 第四步：页面入口 `index.php`

```php
<?php
if (!defined('SYSTEM_INCLUDE')) exit('Access Denied.');

if (!$U->checkRights('device.select')) $A->pageError(ERROR_NO_RIGHTS);

$Q = DB::table('device');
$Q->field(array('dv_id', 'dv_name', 'dv_status', 'dv_inserttime'))
  ->order('dv_id', 'desc');
$items = $Q->rows();

$T->bind('items', $items);
$T->show('device.select');
?>
```

### 第五步：动作接口 `control/index.php`

```php
<?php
include '../../startup.php';

switch ($mode = $A->strGet('mode'))
{
	case 'fc.device.insert':
		if (!$U->checkRights('device.insert')) exit('ERR|'.ERROR_NO_RIGHTS);
		
		$dv_name = trim($A->strPost('dv_name'));
		if ($dv_name == '') exit('ERR|请填写设备名称。|dv_name');
		
		$id = $D->insert('device', array
		(
			'dv_name'       => $dv_name,
			'dv_status'     => 1,
			'dv_inserttime' => time(),
		));
		$A->logInsert('添加了设备 #'.$id);
		echo 'YES';
		break;
		
	case 'fc.device.delete':
		if (!$U->checkRights('device.delete')) exit('ERR|'.ERROR_NO_RIGHTS);
		
		//批量 id 已用正则校验，字符串 where 仅此一种合法用法
		$args = $A->strPost('id');
		if (!preg_match('/^[0-9]+(,[0-9]+)*$/', $args)) exit('ERR|参数错误。');
		
		$D->delete('device', 'dv_id in ('.$args.')');
		echo 'YES';
		break;
}
```

安装模块：登录后台 → 模块管理 → 安装。安装时会自动注册权限、菜单，并由模块 `install()` 回调执行 `install.mysql.sql` 建表。

## 四、数据库 API 总表

**读写分工，一份代码只有一条读路径。**

| 场景 | 入口 | 说明 |
|---|---|---|
| 读 | `DB::table('表名')` | 查询构造器门面，见第五章 |
| 写 | `$D`（`startup.php` 全局提供） | `insert/update/delete/exec/lastId/raw/transaction` |

驱动内部已有 PDO 与参数绑定，**调用方永远不要拼接 SQL 值**。构造器的 `table()` 与写方法的第一参数只写裸表名（如 `content`），前缀由驱动补全；只有 `exec()`/`where()` 里的 SQL 片段才用 `T[content]` 标记。

### 4.1 读取

读只有构造器一个入口，不存在"手写 select 字符串"的写法：

```php
//一行
$rst = DB::table('device')->where('dv_id = ?', array($id))->row();
if ($rst)
{
	echo $rst['dv_name'];
}

//多行
$items = DB::table('device')->where('dv_status = ?', array(1))->order('dv_id', 'desc')->rows();

//单值
$total = DB::table('device')->count();

//首列
$ids = DB::table('device')->where('dv_status = ?', array(1))->column('dv_id');

//是否存在
if (!DB::table('device')->where('dv_name = ?', array($name))->exists())
{
	//...
}
```

`DB::table()` 只是 `FCApplication::query()->table()` 的门面，每次返回新实例，链式状态不会在嵌套调用之间相互污染。

### 4.2 写入

| 方法 | 返回 | 说明 |
|---|---|---|
| `insert($table, array $data)` | `int` | 返回自增 ID |
| `update($table, array $data, $where)` | `int` | 返回影响行数 |
| `delete($table, $where)` | `int` | 返回影响行数 |
| `exec($sql, $params)` | `int` | 执行任意写语句（含 DDL），返回影响行数 |
| `lastId()` | `int` | 最后插入的自增 ID |

```php
$id = $D->insert('device', array
(
	'dv_name'       => $dv_name,
	'dv_status'     => 1,
	'dv_inserttime' => time(),
));

$rowCount = $D->update('device', array('dv_name' => $dv_name), array('dv_id' => $id));

$rowCount = $D->delete('device', array('dv_id' => $id));
```

`$where` 规则：

- **数组**：`array('dv_id' => 1)` → `dv_id = ?`，多个条件用 `AND`。**所有含用户输入的条件必须用数组。**
- **字符串**：原样拼接，仅允许两种已校验的场景：
  - `'dv_id in (1,2,3)'`（id 列表必须先用 `preg_match('/^[0-9]+(,[0-9]+)*$/', $args)` 校验）
  - `'1=1'`（无条件）

### 4.3 表达式：`raw()`

`raw()` 只用于**常量表达式**，不接收任何用户输入。仓库内合法用例仅四类：

```php
//自增计数
$D->update('content', array('ct_hits' => $D->raw('ct_hits + 1')), array('ct_id' => $id));
$D->update('content', array('ct_talks' => $D->raw('ct_talks + 1')), array('ct_id' => $id));
$D->update('attached', array('at_hits' => $D->raw('at_hits + 1')), array('at_id' => $id));

//带子查询的统计（用 exec 并正常绑定参数）
$D->exec(
	'update T[category] set cg_count = (select count(*) from T[content] where ct_cid = ?) where cg_id = ?',
	array($cid, $cid)
);
```

### 4.4 事务

统一用闭包，异常自动回滚并向上抛出。**禁止手写 `beginTransaction/commit/rollback`。**

```php
try
{
	$id = $D->transaction(function($D) use ($name, $tags)
	{
		$id = $D->insert('device', array('dv_name' => $name, 'dv_status' => 1));
		
		foreach ($tags as $tag)
		{
			if (!DB::table('tags')->where('tg_title = ?', array($tag))->exists())
			{
				$D->insert('tags', array('tg_title' => $tag));
			}
		}
		
		return $id;
	});
}
catch (Exception $e)
{
	exit('ERR|保存失败，请重试。');
}
```

### 4.5 状态

```php
$D->connected();      // bool，数据库是否连接成功
$D->inTransaction();  // bool
```

`run()` 是驱动的执行原语，标了 `@internal`，**只允许 `cls.query.php` 调用**。业务代码里出现 `$D->run(` 一律视为违规。

## 五、查询构造器

用于所有"列表 + 条件 + 排序 + 分页"场景，替代手拼 `$where` / `$order` 字符串。

```php
$Q = DB::table('content');
```

`DB::table()` 是 `FCApplication::query()` 的门面，只是省掉重复输入；构造器本身仍是唯一读入口。

### 5.1 方法

| 方法 | 说明 |
|---|---|
| `table($table)` | 指定表（裸表名，如 `'content'`）并**重置全部状态**；表名只允许 `[A-Za-z0-9_]+`，前缀由驱动补全 |
| `field($fields)` | `'a,b'` 或 `array('a','b')`，逐项校验 |
| `fieldRaw($expr)` | 追加字段表达式（常量） |
| `where($sql, $params)` | 追加 `AND` 条件，`?` 绑定 |
| `whereIn($column, array $values)` | 空数组生成 `1=0` |
| `whereRaw($sql)` | 追加常量条件片段 |
| `order($column, $dir='asc')` | 方向仅 `asc`/`desc`，非法抛异常 |
| `orderRaw($expr)` | 追加排序表达式（常量） |
| `limit($count)` / `limit($offset, $count)` | 整数强制转换 |
| `build()` | 返回 `array($sql, $params)` |
| `row()` | 一行，无记录返回 `NULL` |
| `rows()` | 多行，空结果返回 `array()` |
| `value($column, $default)` | 首行首列，无记录返回 `$default` |
| `column($column)` | 首列数组 |
| `count()` | 记录数（内部固定 `count(*)`） |
| `exists()` | 是否存在 |
| `page($pager)` | 统计总数 → 取当前页 → 渲染翻页条，返回当前页数组 |

### 5.2 列表 + 分页

```php
$pager = FCApplication::sharedPageTurnner();
$pager->style = 'Simple';
$pager->size = intval($A->site['site_pagesize']);
$pager->page = $A->strGet('page', 1);

$Q = DB::table('content');
$Q->field(array('ct_id', 'ct_title', 'ct_cid', 'ct_inserttime'))
  ->where('ct_check = 1')
  ->where('ct_cid = ?', array($cid))
  ->order('ct_fixed', 'desc')
  ->order('ct_inserttime', 'desc');

$items = $Q->page($pager);

$T->bind('items', $items);
$T->bind('turnner', $pager->turnner);
```

`page()` 内部先 `count()` 再取当前页，`$pager->build()` 只负责算页码与渲染，**分页器不接触数据库**。

### 5.3 校验规则

| 输入 | 结果 |
|---|---|
| `field('a,b')` | 合法 |
| `field('content.ct_id')` | 合法 |
| `field('a;drop')` | 抛 `Exception` |
| `order('ct_id', 'desc;--')` | 抛 `Exception` |
| `table('content')` | 合法，内部补前缀为 `fc_content` |
| `table('content;drop')` | 抛 `Exception` |

字段名规则：`/^(\*|[A-Za-z0-9_]+(\.[A-Za-z0-9_]+)?)$/`。

### 5.4 `*Raw` 的边界

- `fieldRaw/whereRaw/orderRaw` 只接受**代码里写死的常量**。
- 任何来自请求的参数必须走 `where()` 的 `?` 绑定。
- `whereIn()` 的列名会校验，值逐项绑定。

## 六、模板规范

### 6.1 渲染与绑定

```php
$T->bind('items', $items);
$T->bind('turnner', $pager->turnner);
$T->show('device.select');   // 对应 template/device.select.php
```

模板内可直接使用 `$A $U $D $T $R` 与绑定变量。

### 6.2 循环

```php
<?php foreach ($items as $rst) { ?>
	<tr>
		<td><?php echo intval($rst['dv_id']); ?></td>
		<td><?php echo htmlspecialchars($rst['dv_name'], ENT_QUOTES, 'UTF-8'); ?></td>
	</tr>
<?php } ?>
```

**不要**使用 `while ($rst = $D->fetch($res))`，旧驱动出口已删除。

### 6.3 输出转义

| 内容 | 写法 |
|---|---|
| 数据库字段文本 | `htmlspecialchars($rst['field'], ENT_QUOTES, 'UTF-8')` |
| 请求参数回显（搜索词等） | `htmlspecialchars($A->strGet('keyw'), ENT_QUOTES, 'UTF-8')` |
| 数字 | `intval()` |
| URL 参数 | `urlencode()` |

### 6.4 分页条

```php
<div class="turnner"><?php echo $turnner; ?></div>
```

`$turnner` 由 `pageturnner` 生成，已是 HTML，不要再转义。

### 7.4 批量删除

```php
$args = $A->strPost('id');
if (!preg_match('/^[0-9]+(,[0-9]+)*$/', $args)) exit('ERR|参数错误。');

$D->delete('device', 'dv_id in ('.$args.')');
```

### 7.5 动态筛选

```php
$Q = DB::table('device');
$Q->field(array('dv_id', 'dv_name'));

$keyw = trim($A->strGet('keyw'));
if ($keyw != '') $Q->where('dv_name like ?', array('%'.$keyw.'%'));

if ($status != '') $Q->where('dv_status = ?', array(intval($status)));
```

### 7.6 统计与计数

```php
$total = DB::table('device')->count();

$online = DB::table('device')->where('dv_status = ?', array(1))->count();
```

`count()` 无参数，内部固定 `count(*)`；`DB::table()` 每次返回新实例，链式状态互不干扰。

### 7.7 模块统一配置页（fc.settings）

每个模块都可以提供一个统一的模块配置页面，约定固定：

- `module.php` 声明权限 `模块名.settings`（如 `content.settings`），菜单 URL 写 `fc.settings`；
- `index.php` 增加 `case 'fc.settings'`，校验权限后展示配置模板；
- 配置页完全参照 system 的 `fc.settings` 表单排版：含保存与取消按钮，点保存一次性提交整个表单，由 `control` 写回模块的 `*.settings.php`（自动化文件，不走手工配置）。

### 7.8 附件链接与下载

```php
//上传成功后返回的下载地址走 token 页面路由，不要直接拼物理路径
$pipe = $R->getPageUrl('system/file/'.$atToken, '', DIR_SITE);
```

- 模板中展示附件用 `$A->fileIcon($suffix)` 取图标，图片可用 `$A->getThumb()` 取缩略图；
- 附件下载、远程附件、Range 续传均由 system 的 `file` 入口统一处理，业务模块不要自行实现下载输出。

### 7.9 皮肤与模块图标

- 取皮肤目录用 `$U->getSkin()`，不要在模块里写死皮肤名；
- 模块图标随皮肤切换时，用 `$A->moduleIcon($module, $file)` 取当前皮肤版本，自动回退默认皮肤；
- 模块私有图标放自身 `icons/`，菜单与桌面引用相对文件名即可。

第三方控件的配色要跟皮肤走，别直接硬编码：

- **日期控件**：调用点写 `WdatePicker({skin:'<?php echo DATE_SKIN; ?>'})`。`DATE_SKIN` 会自动匹配 `tools/datepicker/skin/<皮肤名>/`，不存在时回落 `default`，所以新增皮肤只要复制一份 `datepicker.css` 就能一起变色；
- **富文本**：`fc.quill.css` 已用设计令牌适配，只需保证它加载在 `quill.snow.css` 之后；
- **模块私有样式**：一律用 `var(--surface)`、`var(--line)`、`var(--text-2)` 之类的令牌，写死 `#fff` / `#f3f3f3` 在暗色皮肤下会直接破相。

### 7.10 登录失败限流与反向代理

登录动作 `fc.user.login` 自带失败限流，实现见 `module/member/library/cls.loginlimit.php`，不需要新建数据表：

- **维度**：IP 与账号双计数（账号不区分大小写），任一维度超限即拒绝登录；
- **阈值**：`store/config/system.settings.php` 中的 `loginAttempts`（窗口内允许失败次数，默认 5）、`loginWindow`（统计窗口，分钟）、`loginLock`（锁定时长，分钟）；
- **存储**：`store/cache/login/` 下的 `ip_<md5>.php` / `us_<md5>.php`，文件以 `<?php exit; ?>` 开头防直接访问，读写用 `flock(LOCK_EX)` 原子更新，锁定期满或窗口过期自动清零；
- **提示**：失败只回“用户名或密码不正确，还可以试 N 次”，不区分账号是否存在。

取客户端 IP 统一用 `$A->getUserIP()`：默认只认 `REMOTE_ADDR`——`HTTP_CLIENT_IP`、`HTTP_X_FORWARDED_FOR` 可被客户端任意构造，默认忽略；IPv4 与 IPv6 全量地址均可识别（含 `[::1]:8080`、`1.2.3.4:5678` 这类带端口写法）。

站点若跑在 CDN 或 Nginx 反代之后，必须在 `system.settings.php` 里显式开启：

```php
'trustProxy'     => 1,
'trustProxyList' => '10.0.0.1,10.0.0.2',   //反代的直连 IP，逗号分隔
```

只有直连 IP 命中白名单时才采纳 `X-Forwarded-For`，并取其中最左侧一个合法地址；不开 `trustProxy` 时反代后面所有访客会被算成同一个 IP。

### 7.11 伪静态与 Web 服务器配置

站点根目录指向 `src/`，除真实存在的文件/目录外，所有请求交给 `index.php`。不配伪静态时 `/?系统` 可用、`/系统` 会 404。

**Nginx**（宝塔：网站 → 设置 → 伪静态，粘贴）

```nginx
location / {
    try_files $uri $uri/ @fcontex;
}
location @fcontex {
    rewrite ^/(.*)$ /index.php?$1 last;
}
```

**Apache**：随包 `src/.htaccess` 已含等价规则，`AllowOverride` 需允许读取；站点根不是 `src/` 时，把 `.htaccess` 里的规则写进 `<Directory>` 段。

**IIS**：在站点根自建 `web.config`，`<system.webServer><rewrite><rules>` 内放

```xml
<rule name="fcontex" stopProcessing="true">
    <match url="^(.*)$" ignoreCase="false" />
    <conditions logicalGrouping="MatchAll">
        <add input="{REQUEST_FILENAME}" matchType="IsFile" ignoreCase="false" negate="true" />
        <add input="{REQUEST_FILENAME}" matchType="IsDirectory" ignoreCase="false" negate="true" />
    </conditions>
    <action type="Rewrite" url="/?{R:1}" appendQueryString="false" />
</rule>
```

**目录保护**（`!-e` 会放行真实目录，所以要补下面几条；按目录收窄，整段 deny `/module/` 或 `/store/` 会打死后台动作接口与附件）

```nginx
location ~ ^/module/[^/]+/(library|template)/ { deny all; }
location ^~ /store/config/ { deny all; }
location ^~ /store/cache/login/ { deny all; }
location ^~ /install/ { deny all; }
location ~* \.(sql|md|bak|log|ini|sh)$ { deny all; }
```

Apache 的后缀拦截已写在随包 `.htaccess` 里，不需另加。

**验证**

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://你的域名/system    # 期望 200
curl -s -o /dev/null -w '%{http_code}\n' https://你的域名/无此页面  # 期望 404（框架自己的 404 页）
```

## 八、禁忌清单

1. **禁止拼接 SQL 值**。`where('dv_name = \''.$name.'\'')` 一律不允许，必须 `where('dv_name = ?', array($name))`。
2. **禁止把用户输入传给 `field()/order()/table()`**。这些位置只接受代码里写死的标识符。
3. **禁止调用 `$D->run()`**。它是驱动的执行原语（`@internal`），全库只允许 `cls.query.php` 调用；读取一律用 `DB::table()`。
4. **禁止手写 `beginTransaction/commit/rollback`**。用 `$D->transaction(function($D){...})`。
5. **表名参数只写裸表名**（如 `'device'`），禁止手写物理表名或 `T[...]`；前缀由驱动补全。SQL 片段中的表名仍用 `T[表名]` 标记。
6. **禁止滥用 `raw()`**。只用于自增计数、子查询统计等常量表达式。
7. **禁止字符串 where 携带用户输入**。字符串 where 只允许已正则校验的 `in (...)` 和 `1=1`。
8. **禁止在模板里写 `query/fetch/fetchAll`**。模板只消费控制器传入的数组。
9. **禁止直接 echo 请求参数**。必须 `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`。

## 九、AI 协作约定

本节写给自动改代码的 agent，同样适用于人类贡献者。

### 9.1 稳定锚点

- 文档标题层级固定：`## 一、…` 到 `## 十、…`，小节 `### x.y`。
- 需要引用时使用锚点，例如 `#四数据库-api-总表`、`#72-详情页`。
- 新增章节追加在对应大节末尾，不重排既有编号。
- 仓库根目录的 `AGENTS.md` 是给 AI 的项目入口，先读它再动手，本指南是其展开细则；新模块优先用 `bin/newmodule.php` 脚手架生成。

### 9.2 代码块约定

- 每段代码必须标注语言：`php` / `sql` / `bash` / `html`。
- 示例必须**自包含、可整段复制**，不出现 `// ...省略`。
- 涉及多个文件时，先写文件路径再写代码块。

### 9.3 改代码时的检索顺序

1. `grep -r "关键字" src/module` 找调用点。
2. 读完整文件再改，禁止只看片段。
3. 改完执行 `php -l <file>`。
4. 残留扫描：`->query(`、`->fetch(`、`->fetchAll(`、`->insertid(`、`->escape(`、`strSQL(`、`DB_TYPE`。

### 9.4 代码风格（必须一致）

- 缩进用 **Tab**，不用空格。
- 数组用 `array()`，不用 `[]`。
- 注释用中文，函数上方用 `/*** ... */`。
- 类文件命名 `cls.<name>.php`，放 `library/`。
- 方法命名小驼峰，数据库字段用 `表前缀_字段` 两字母缩写。
- 文件头保留作者与官网注释。

### 9.5 判断新代码是否合规的三问

1. 有没有把值拼进 SQL 字符串？→ 必须改成 `?` 绑定。
2. 表名是否写成了 `T[...]` 或物理表名？→ 改回裸表名。
3. 列表查询有没有走构造器？→ 有分页就必须走。

## 十、术语表

| 术语 | 含义 |
|---|---|
| 模块 | `src/module/<name>/`，唯一扩展机制，可安装/禁用/卸载 |

| 驱动出口 | `run`（`@internal`，仅供构造器）、`exec`、`insert/update/delete` |

| 分页器 | `pageturnner`，`build($total)` 只算页码与渲染，不接触数据库 |
