# FContex Admin

> 为 AI 开发而生，也为不一样的管理界面而生——纯 PHP、零构建链的模块化管理后台框架。

FContex Admin 是一个轻量级管理后台开发框架，用于快速构建各类需要后台管理界面的系统：业务后台、运营工具、ERP、APP后台、小程序后台、企业网站等。它的前身是 2012 年发布的 fcontex CMS（最后公开发布版本 1.0.4），现转型为面向管理类系统的开发框架。

**适合**：中小规模的内部系统与自用后台——设备管理、进销存、ERP、CRM、工单等需要按业务定制的场景；希望长期自己维护、代码量可控、能把模块交给 AI 生成的团队。

**不适合**：两周内必须上线且依赖大量现成功能的项目；需要插件市场与活跃社区支撑的团队——FContex 生态现处于起步阶段，没有插件市场与第三方教程。

## 亮点

1. **AI 开发（AI-first）**：单语言、强约定、小体积——135 个 PHP 文件、约 1.75 万行、0.55 MB，整个项目可装进一个 AI 上下文；命名约定唯一（模块名 → `FCModule` 类 → `fc.mode` 动作 → 权限键），AI 可直接生成模块、补权限并自检
2. **告别千篇一律的管理界面**：类 OS 的窗口化控制台，支持窗口多开、开始菜单、任务栏，图标随模块装卸自动增减；双皮肤 default/dark 支持用户级跟随
3. **零构建链**：纯 PHP + 服务端渲染，无 Node、Vite、Composer，拷贝即部署
4. **模块热插拔**：内核仅 system + member，其余皆为可装卸模块；模块自带数据表、权限、菜单与生命周期，后台一键安装/停用/卸载
5. **声明式权限**：模块在 `module.php` 中声明权限，安装时注册；操作级权限闭环，简洁完整，无节点扫描
6. **响应式界面**：适配移动端访问，列表在容器内横向滚动、首列固定，后台管理不受设备限制
7. **轻量可通读**：全部代码自包含、无黑盒，出问题能直接定位到具体一行

## 环境要求

- PHP 7.3 及以上（需启用 `pdo_mysql`、`session`，`gd` 缩略图扩展可选），推荐 8.2
- MySQL 5.5 及以上（utf8mb4 + utf8mb4_general_ci），推荐 5.7 / 8.0
- Apache / Nginx / IIS 等 WEB 服务器（Apache 随包附 `src/.htaccess`；Nginx / IIS 的伪静态配置见 `docs/03.开发指南.md` 第 7.11 节）

## 快速开始

1. 将 `src` 目录下的所有文件拷贝到 WEB 服务器的站点目录
2. 浏览器访问 `http://你的域名/install`
3. 按安装向导提示完成安装

安装完成后请删除 `install` 目录。站点页面提供控制台登录入口，登录后即进入 WebOS 窗口化后台桌面。

## 目录结构

```
├── LICENSE               MIT 协议
├── README.md             本文件
├── docs/                 项目文档
└── src/                  源代码
    ├── module/
    │   ├── system/       内核模块（不可卸载）
    │   ├── member/       用户与权限模块（不可卸载）
    │   ├── content/      内容模块
    │   ├── message/      留言模块
    │   └── ...           其它业务模块
    ├── store/            运行时存储（配置、缓存、上传）
    └── install/          安装向导
```

## 与同类框架对比

| | FContex Admin | FastAdmin | BuildAdmin |
|------|------|------|------|
| 后端 | 自研内核（纯 PHP） | ThinkPHP 5 | ThinkPHP 8 |
| 前端 | 服务端渲染，无构建 | jQuery + RequireJS | Vue3 + TS + Vite |
| 后台形态 | 类 OS 的窗口化 | 传统侧栏式 | 传统侧栏式 |
| 权限 | 声明式，操作级 | 节点规则 | 节点规则 |
| 部署 | 拷贝即部署 | 常规 | 前端需构建（提供发行包） |

差异化的本质：FContex Admin 认为，AI 时代，开发工作轻装上阵反而会更灵活且更容易掌控，所以同类框架在加码能力，FContex Admin 在降低负担。
